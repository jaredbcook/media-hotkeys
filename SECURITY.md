# Security

Media Hotkeys runs a content script on every page, so security problems matter even though it makes no network requests and stores only your settings.

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/jaredbcook/media-hotkeys/security/advisories/new), not in a public issue. Include the browser and version, the page or setup that shows the problem, and what an attacker could do with it.

Fixes ship in the next release. Only the latest version is supported.
